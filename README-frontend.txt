GEL — Professional Personal AI Prototype

WHAT WORKS NOW
- Professional responsive dashboard
- Login screen and session gate (frontend demo)
- One GEL account concept with 4 authorized-device slots
- Home navigation and working sections
- Daily Journal saved locally in the browser
- Idea Engine prototype
- Account Wallet prototype with masked credentials
- YouTube search button opens YouTube search
- Settings save locally
- Sign out
- Responsive desktop/mobile layout

IMPORTANT
This is a frontend prototype, not production authentication. Do not put real passwords/API keys in app.js or the browser. For the real GEL, we should add a server-side auth system, HTTPS, secure cookies/sessions, device/session management, encrypted secrets, and optional passkeys/MFA. OWASP recommends secure server-side session management and re-authentication for sensitive operations.
